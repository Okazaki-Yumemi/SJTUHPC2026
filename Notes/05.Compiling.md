# Introduction to Compile.

```
编译是什么？

编译是将便于人编写、阅读、维护的高级计算机语言所写作的源代码程序，翻译为计算机能解读、运行的低阶机器语言的程序，也就是可执行文件。

编译器将原始程序（source program）作为输入，翻译产生使用目标语言（target language）的等价程序。

源代码一般为高级语言（High-level language），如 Pascal、C、C++、C# 、Java 等，而目标语言则是汇编语言或目标机器的目标代码（Object code），有时也称作机器代码（Machine code）。

```


# 机器语言、汇编语言、高级语言
---

- 机器语言

机器语言是最底层的编程语言，能被计算机的CPU直接理解，它完全由二进制代码构成，表示CPU的可执行的原始指令。

- 特点
- - 二进制格式: 机器语言指令以二进制 (0 or 1 ) 编写，因为计算机硬件通过电信号的开 / 关来识别指令
- - 架构特定性: 因为底层设计是差异的
- - 无抽象: 机器语言最贴近硬件，不提供任何抽象，程序员需要直接管理内存、数据操作和控制
- example:
- - `10001001 11011000` 可能代表把寄存器BX的内容送进寄存器AX


- 汇编语言
汇编语言是一种低级编程语言，是机器码的符号化表示，相对便于记忆。每条汇编指令直接对应一条机器码指令，但是代码使用可读的文本和助记符和非二进制。

- 特点
- - 可读性: 采用助记符（MOV，ADD）代替二进制，比机器码更容易理解
- - 一对一映射: 每条汇编指令对应特定CPU架构的一条机器码指令
- - 架构特定性: 汇编语言和CPU架构精密绑定，不同的机器汇编程序需要修改才能运行
- - 精细控制: 允许直接操作寄存器，内存地址等硬件资源


- 高级语言
高级语言是抽象层级更高的编程语言，更贴近人类语言，编程更便捷。目标是跨硬件的平台的可移植性

- 特点:

- - 高抽象: 隐藏了硬件细节，让开发者专注于问题解决
- - 可移植性： 程序通常无需修改就可以在不同的计算机上面运行，编译器/解释器会处理硬件差异
- - 丰富的lib支持
- - 易读性: 语法接近自然语言，代码更容易编写and 维护
- - 自动内存管理: 许多高级语言自动回收垃圾内存，无需手动干预。


# 解释性语言和编译性语言

- 编译性语言:
编译型语言指在执行之前需要将源代码编译（compile）为机器代码的编程语言，使用“编译器”。

执行前需要编译，将程序转换为可在目标机器上运行的可执行文件，执行速度快。但每次修改源代码后，都需要重新编译，生成新的可执行文件。

包括C C++ RUST Go

- 解释性语言:

解释型语言指执行期间动态将代码逐句解释为机器代码，或者是已经预先编译好了的为机器代码的子程序，之后再执行的编程语言。

解释型语言可快速调试，程序开发的整体相对时间比较少，但是由于需要在运行的时候转换为机器代码，解释型语言通常编译型语言更慢

解释型语言包括 JavaScript, Python， MATLAB等

**JIT 即时编译，Just in time compilation 是一种执行计算机代码的方式，这种方式结合了解释执行和预先编译的优点**

# 编译的流程

下面以 g++ 编译 hello.cpp 文件为例，介绍编译的流程。

```markdown

常见的 C/C++ 编译器主要有以下两种

- GCC（GNU Compiler Collection）是一个开源的编译器集合，支持多种编程语言，包括 C 和 C++。
- - gcc 用于 C 语言的编译
- - g++ 用于 C++ 的编译（兼容 C 语言的编译）
- LLVM（Low Level Virtual Machine）是一个开源的编译器基础设施项目，由一系列的模块化和可重用的编译器组件构成，支持广泛的编程语言，包括但不限于 C、C++。
- - clang 用于 C 语言的编译
- - clang++ 用于 C++ 的编译（兼容 C 语言的编译）

```

1. 预处理阶段:

- 移除注释
- 处理预处理指令，如 `#include` 和宏定义，生成预处理文件(.i)
```bash
g++ -E hello.cpp -o hello.i
```

2. 编译阶段:
- 将预处理后的代码转换成汇编语言，生成汇编文件
```bash
g++ -S hello.i -o hello.s
```

3. 汇编阶段
- 将汇编语言转换成机器代码，生成二进制文件
```bash
g++ -c hello.s -o hello.o
```

4. 链接阶段
- 将编译生成的目标文件和库文件连接在一起，生成可执行文件
```bash
g++ hello.o -o hello
```

上述四个步骤也可以一步完成
```bash
g++ hello.cpp -o hello
```

#include <iostream>
#include <chrono>

int main() {
    const long long N = 200000000;
    double result = 0;

    auto start = std::chrono::high_resolution_clock::now();

    for (long long i = 0; i < N; ++i) {
        result += i;
        result /= 3;
        result /= 3;
        result /= 3;
    }

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    std::cout << "Result: " << result << "\n";
    std::cout << "Time: " << duration.count() << " ms" << std::endl;

    return 0;
}
